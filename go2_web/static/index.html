局部目标与测试范围
目标用启动时机身坐标设置：前方为正X，左侧为正Y。启动后固定到本体里程计坐标系，不会每帧向前推移。它是局部目标，不是全局地图导航。首次实际试验仅支持前方0.3–0.5米、侧向0、速度≤0.10m/s、时长≤5秒；原地/近障停车不受最低非停车采样速度影响。初步标定必须单独确认，完整标定仍需实际测量。切换页面、页面失联或输入过期会终止执行；遥控器仍需现场接管。
