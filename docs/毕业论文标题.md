# 第三章方法总名可以叫：双层代价场引导的足迹约束 U-MPPI 局部规划方法


# 研究内容一：基于双层代价场的局部路径引导方法
针对有限视野深度感知下局部避障中安全性与通行性难以兼顾的问题，提出基于双层代价场的局部路径引导方法。该方法将传统固定膨胀 FMM 改进为硬碰撞层与软安全代价层相结合的传播形式，在保证障碍不可碰撞约束的同时，引导机器人在可通行区域内保持更大障碍净空，从而改善贴边绕障和窄通道通行之间的矛盾。
# 研究内容二：融合足迹约束与无迹引导的 MPPI 局部规划方法

针对质点路径难以描述四足机器人机身尺寸约束、普通 MPPI 在障碍密集场景中易陷入局部低代价轨迹的问题，提出融合足迹约束与无迹引导的 MPPI 局部规划方法。该方法在 FMM 参考路径基础上引入 Go2 矩形机身足迹，对候选速度序列进行短时轨迹预测与碰撞检查，并结合 U-MPPI 的 sigma-point 状态传播和风险敏感代价，提高复杂障碍场景下的探索能力和轨迹可执行性。


相比之前 4 轮小模型的 mIoU=0.542、high IoU=0.277，正式模型明显学到了更好的 D435i 可通行性风险识别能力。
但接到导航里以后，结果没有简单变好：
- 正式模型默认权重导航：3 次成功 2 次
- 降低风险代价权重后：3 次全失败
这说明现在的问题不是“模型没训好”，而是“预测风险图接入 U-MPPI 的几何方式还比较粗糙”。正式模型更敏感，会把更多区域判断为风险，结果在当前仿真重放式 pred_cost 接口里反而容易干扰局部规划。
