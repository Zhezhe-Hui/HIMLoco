# 第四章实验结果整理稿

本文档用于从实验记录中提取论文第四章可直接使用的结果。完整命令、日志和调试过程见 `docs/第四章可通行性风险导航实验记录_20261008.md`。

## 1. 本章研究内容定位

第四章建议凝练为两块研究内容：

**研究内容三：基于 D435i 视觉感知的可通行性风险估计方法。**  
针对野外环境中草地、碎石、岩石等区域不能仅由几何高度判断是否可通行的问题，利用与实机硬件匹配的 RealSense D435i 开源数据集，将地形语义标签转换为低风险、中风险和高风险三类可通行性标签，并训练轻量级语义风险预测网络，生成 `pred_cost` 风险代价图。

**研究内容四：融合学习式风险图的 U-MPPI 局部导航方法。**  
针对传统局部规划器只关注硬障碍、难以表达软风险地形的问题，将学习得到的 `pred_cost` 风险图接入第三章已有的 `TRAVERSABILITY_COST / U-MPPI` 代价接口，使风险图同时影响 FMM 参考路径传播和 U-MPPI 候选轨迹评价，形成学习式可通行性风险导航闭环。

## 2. 数据集与标签构建

本章主线采用 BASEPROD-D435i 数据集，原因是其采集设备为 Intel RealSense D435i，与后续 Unitree Go2 EDU + D435i 实机平台更接近。

| 内容 | 数值 |
| --- | ---: |
| 数据集 | BASEPROD_labeled FRAMED |
| RGB 图像 | 950 |
| Depth 图像 | 950 |
| 原始语义标签 | 950 |
| 转换后数据大小 | 约 228 MB |
| 低风险像素占比 | 52.13% |
| 中风险像素占比 | 25.08% |
| 高风险像素占比 | 1.35% |
| 忽略像素占比 | 21.44% |

标签合并规则如下：

| 风险类别 | 对应地形 |
| --- | --- |
| 低风险可通行 | compact, grass, sandy |
| 中风险可通行 | bedrock, pebble, vegetation |
| 高风险/障碍 | rock |
| 忽略 | void |

这里的关键点是：草地和砂地不被简单视为障碍，而被建模为可通行区域；碎石、植被等区域作为中风险地形；岩石作为高风险区域。这与野外实机部署需求是一致的。

## 3. 可通行性风险感知结果

训练模型为轻量 TinyUNet，输入 RGB 图像，输出低/中/高三类风险图。正式模型配置为 `144x256` 输入分辨率、`width_mult=16`、训练 `30 epoch`，类别权重为 `1.0,1.3,8.0`，用于缓解高风险 rock 类样本占比过低的问题。

| 实验 | Pixel Acc | mIoU | 低风险 IoU | 中风险 IoU | 高风险 IoU |
| --- | ---: | ---: | ---: | ---: | ---: |
| BASEPROD 4 epoch 默认权重 | 0.825 | 0.473 | 0.774 | 0.615 | 0.030 |
| BASEPROD 4 epoch 类别加权 | 0.823 | 0.542 | 0.792 | 0.557 | 0.277 |
| BASEPROD 30 epoch 正式模型 | 0.913 | 0.722 | 0.888 | 0.775 | 0.502 |
| 正式模型导出 128 张验证 | 0.947 | 0.726 | 0.941 | 0.709 | 0.528 |

从结果看，类别加权对高风险类非常关键：高风险 IoU 从 `0.030` 提升到 `0.277`。正式训练后，高风险 IoU 进一步提升到 `0.502`，说明模型已经具备识别岩石等高风险区域的能力。

## 4. 学习式风险图接入导航结果

当前闭环验证采用 `pred_cost replay` 形式：先由感知模型离线导出 `pred_cost/*.png`，再由 `PredCostTraversabilityProvider` 将灰度风险图重采样为局部 BEV 风险代价图，并接入 FMM 与 U-MPPI。

| 风险图来源 | 成功率 | 平均到达时间 | 平均规划耗时 | 平均路径风险 | 路径 p95 风险 | 说明 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| RUGD pred_cost | 3/3 | 35.52 s | 13.03 ms | 0.633 | 0.749 | 验证学习式风险闭环可跑通 |
| BASEPROD 4 epoch 加权模型 | 3/3 | 37.07 s | 14.87 ms | 0.024 | 0.109 | D435i 小模型闭环 smoke 成功 |
| BASEPROD 30 epoch 正式模型，默认权重 | 2/3 | 34.49 s | 15.78 ms | 0.078 | 0.219 | 1 次 Timeout |
| BASEPROD 30 epoch 正式模型，低权重 | 0/3 | - | - | - | - | 2 次卡住，1 次 Timeout |

该结果说明：学习式风险图已经能够进入 U-MPPI 闭环，但感知精度提升不必然带来导航稳定性提升。正式模型比 4 epoch 小模型更敏感，对高风险区域识别更强，但当前 `pred_cost replay` 几何适配还比较粗糙，风险图与局部规划坐标之间存在耦合问题，因此闭环表现反而更保守。

## 5. 论文中建议采用的结论

第四章可以形成一个比较完整但不过度扩张的结论：

1. 通过 D435i 开源野外数据构建了低/中/高三类可通行性风险标签，使草地、砂地、碎石、岩石等区域不再被简单二值化为“障碍/非障碍”。
2. 类别加权训练显著改善了高风险 rock 类识别能力，正式模型在验证集上取得 `mIoU=0.722`、高风险类 `IoU=0.502`。
3. 将学习式 `pred_cost` 接入 FMM 和 U-MPPI 后，形成了“视觉风险估计 + 风险感知局部规划”的闭环，证明该方法具备接入现有导航系统的可行性。
4. 闭环导航结果表明，风险图质量、风险代价权重和局部 BEV 几何适配共同影响导航稳定性；仅提高分割精度并不能保证闭环导航效果同步提升。

## 6. 第四章推荐写作结构

### 4.1 问题描述

写野外场景下的可通行性判断问题：草地、碎石、岩石等区域在深度或高度图上可能都不是硬障碍，但对四足机器人来说通行风险不同。传统二值障碍地图不能表达这种差异。

### 4.2 可通行性风险标签构建

写 BASEPROD-D435i 数据集、标签合并规则、低/中/高风险定义。强调它与 Go2 EDU + D435i 硬件更匹配。

### 4.3 轻量化风险预测网络

写 TinyUNet、输入输出、类别加权损失、训练配置。核心表格用第 3 节感知结果表。

### 4.4 融合风险图的 U-MPPI 局部规划

写 `pred_cost` 进入 FMM 和 U-MPPI 的方式：

- FMM 中高风险区域传播速度降低；
- U-MPPI 中候选轨迹经过高风险区域时代价增加；
- 最终形成风险感知的局部导航。

### 4.5 实验结果与分析

先写感知效果提升，再写闭环 smoke 结果。对正式模型导航结果要如实分析：它证明了接口可行，但也暴露出在线投影和平滑仍需进一步完善。

## 7. 后续不建议继续做的事

短期内不建议继续盲目增加训练 epoch 或只调风险权重。现有结果已经说明瓶颈转移到了风险图到局部 BEV 的几何适配，以及风险图时序平滑问题。

更有价值的下一步是：

1. 生成更规整的论文图：数据集标签示例、预测示例、IoU 曲线、导航结果表。
2. 如果继续做实验，优先做 `pred_cost` 平滑或在线 RGB 到 BEV 投影，而不是继续单纯训练更大的模型。
3. 在论文中把正式模型作为感知主结果，把 4 epoch 加权模型作为闭环 smoke 成功案例，避免把当前闭环结果硬解释成“正式模型一定更优”。
