# 第三章方法公式与符号说明

本文档对应当前 HIMLoco 工程实现，覆盖第三章使用的视觉几何建图、固定膨胀 FMM、
双层代价 FMM、机身足迹 MPPI、HIMLoco 底层控制以及 SAPF、PS-DWA、iPlanner 对比方法。
公式可直接复制到支持 LaTeX 的论文编辑器。每组公式后的符号表给出该组公式中全部符号的含义。

> 方法归属说明：双层代价 FMM 引导的足迹 MPPI 是本文上层规划方法；HIMLoco 是本文前期完成的
> 底层强化学习控制器；固定膨胀 FMM 和双层代价 FMM 是内部消融；SAPF、PS-DWA、iPlanner
> 是外部比较方法。当前正式方法关闭时序障碍记忆，因此不把时序记忆列为论文贡献。

## 1. 深度图反投影与局部 BEV 建图

公式图片：![深度图反投影与BEV建图](formula_images/01_depth_to_bev.png)

### 1.1 相机内参

根据图像尺寸和水平视场角计算针孔模型焦距：

$$
f_x=\frac{W}{2\tan(\phi_h/2)},
\qquad
\phi_v=2\arctan\left(\tan(\phi_h/2)\frac{H}{W}\right),
\qquad
f_y=\frac{H}{2\tan(\phi_v/2)}.
$$

像素的归一化坐标为

$$
\delta_u=\frac{u-c_x}{f_x},
\qquad
\delta_v=\frac{v-c_y}{f_y}.
$$

| 符号 | 含义 |
| --- | --- |
| $W,H$ | 深度图宽度和高度，单位为像素 |
| $\phi_h,\phi_v$ | 相机水平和垂直视场角，单位为弧度 |
| $f_x,f_y$ | 水平和垂直方向等效焦距，单位为像素 |
| $(u,v)$ | 当前深度像素坐标 |
| $(c_x,c_y)$ | 图像主点，当前实现取图像中心 |
| $\delta_u,\delta_v$ | 像素相对光轴的归一化横向和纵向偏移 |

### 1.2 轴向深度反投影

Isaac Gym 深度图按光轴方向给出轴向深度。考虑相机俯角后，像素反投影到机器人坐标系：

$$
\begin{aligned}
x &= d(\cos p-\delta_v\sin p),\\
y &= s_l\delta_u x,\\
z &= h_c-d(\sin p+\delta_v\cos p).
\end{aligned}
$$

| 符号 | 含义 |
| --- | --- |
| $d$ | 深度图给出的轴向深度，单位为米 |
| $p$ | 相机光轴向下的俯角，单位为弧度 |
| $h_c$ | 相机相对局部地面的安装高度，单位为米 |
| $s_l$ | 横向坐标符号标定系数，当前链路用于统一图像与 BEV 左右方向 |
| $(x,y,z)$ | 点在机器人局部坐标系中的前向、横向和高度坐标，单位为米 |

### 1.3 BEV 栅格与障碍判定

设 BEV 分辨率为 $r_b$，则三维点对应的栅格索引为

$$
i=\left\lfloor\frac{x}{r_b}\right\rfloor,
\qquad
j=\left\lfloor\frac{y+Y_b/2}{r_b}\right\rfloor.
$$

同一栅格内聚合最低高度、最高高度和点数。基本障碍判据为

$$
O_{ij}=\mathbb I\left[
n_{ij}\ge n_{\min}
\ \land\ 
(z^{\max}_{ij}-z^{\min}_{ij})>h_{\mathrm{th}}
\right].
$$

为检出正对相机的石头或垂直台阶，工程实现还比较相邻前向栅格：

$$
O^{\mathrm{step}}_{ij}=\mathbb I\left[
z^{\max}_{ij}-z^{\min}_{i-s,j}>h_{\mathrm{step}}
\right],
\qquad
O\leftarrow O\lor O^{\mathrm{step}}.
$$

| 符号 | 含义 |
| --- | --- |
| $r_b$ | BEV 单元格分辨率，单位为米/格 |
| $Y_b$ | BEV 横向覆盖宽度，单位为米 |
| $(i,j)$ | 前向和横向栅格索引 |
| $z^{\min}_{ij},z^{\max}_{ij}$ | 栅格内点云最低和最高高度 |
| $n_{ij}$ | 落入栅格 $(i,j)$ 的有效点数 |
| $n_{\min}$ | 判定有效栅格所需的最少点数 |
| $h_{\mathrm{th}}$ | 同格高度差障碍阈值 |
| $s$ | 跨格台阶判据的前向比较跨度，当前通常取 1 格 |
| $h_{\mathrm{step}}$ | 跨格台阶高度阈值 |
| $\mathbb I[\cdot]$ | 指示函数，条件成立为 1，否则为 0 |
| $\lor$ | 二值逻辑或运算 |

## 2. 固定膨胀 FMM 基线

公式图片：![固定膨胀与双层代价FMM](formula_images/02_fmm_cost_layers.png)

### 2.1 固定障碍膨胀

原始 FMM 基线将机器人近似为质点，通过固定半径对二值障碍做形态学膨胀：

$$
\mathcal O_{\mathrm{fix}}=\mathcal O\oplus\mathcal B(r_{\mathrm{fix}}).
$$

在自由区域中求解 Eikonal 方程：

$$
\|\nabla D(\mathbf q)\|_2=1,
\qquad
D(\mathbf q_g)=0,
\qquad
\mathbf q\notin\mathcal O_{\mathrm{fix}}.
$$

机器人沿距离场负梯度方向或其提取路径的前视点运动：

$$
\theta_d=\operatorname{atan2}(y_l,x_l),
\qquad
\omega=\operatorname{clip}(k_\theta\theta_d,-\omega_{\max},\omega_{\max}).
$$

| 符号 | 含义 |
| --- | --- |
| $\mathcal O$ | 原始 BEV 障碍栅格集合 |
| $\mathcal B(r_{\mathrm{fix}})$ | 半径为 $r_{\mathrm{fix}}$ 的圆盘结构元素 |
| $\oplus$ | Minkowski 和，对应障碍形态学膨胀 |
| $r_{\mathrm{fix}}$ | 固定膨胀半径，当前基线为 $0.25\,\mathrm m$ |
| $D(\mathbf q)$ | 栅格 $\mathbf q$ 到目标的 FMM 距离场 |
| $\nabla D$ | 距离场空间梯度 |
| $\mathbf q=(i,j)$ | 当前栅格位置 |
| $\mathbf q_g$ | 局部目标栅格 |
| $(x_l,y_l)$ | FMM 路径前视点在机器人坐标系中的位置 |
| $\theta_d$ | 期望偏航误差 |
| $k_\theta$ | 偏航比例增益 |
| $\omega,\omega_{\max}$ | 输出角速度及其最大绝对值 |

## 3. 双层代价 FMM

### 3.1 障碍净空与硬碰撞层

栅格到最近原始障碍的欧氏距离为

$$
d(\mathbf q)=\min_{\mathbf o\in\mathcal O}
\|\mathbf q-\mathbf o\|_2.
$$

只使用较小硬半径生成绝对不可通行层：

$$
\mathcal O_h=\mathcal O\oplus\mathcal B(r_h).
$$

### 3.2 连续软安全代价

硬层外、软安全距离内使用连续衰减代价：

$$
C_s(\mathbf q)=
\left[
\operatorname{clip}\left(
\frac{r_s-d(\mathbf q)}{r_s-r_h},0,1
\right)
\right]^p.
$$

FMM 传播速度定义为

$$
F(\mathbf q)=\frac{1}{1+w_sC_s(\mathbf q)},
\qquad
F(\mathbf q)=0\quad(\mathbf q\in\mathcal O_h).
$$

到达时间场满足

$$
\|\nabla T(\mathbf q)\|_2F(\mathbf q)=1,
\qquad
T(\mathbf q_g)=0.
$$

当前参数为 $r_h=0.20\,\mathrm m$、$r_s=0.65\,\mathrm m$、$w_s=4.0$、$p=2.0$。

| 符号 | 含义 |
| --- | --- |
| $d(\mathbf q)$ | 栅格到最近原始障碍的净空距离 |
| $\mathbf o$ | 原始障碍集合中的一个障碍栅格 |
| $\mathcal O_h$ | 硬碰撞层，即绝对不可通行区域 |
| $r_h$ | 硬碰撞半径 |
| $r_s$ | 软安全代价影响距离，且 $r_s>r_h$ |
| $C_s$ | 归一化连续软安全代价，取值 $[0,1]$ |
| $p$ | 软代价曲线指数 |
| $w_s$ | 软代价传播权重 |
| $F$ | FMM 局部传播速度，软代价越高则速度越小 |
| $T$ | 加权到达时间场，不等同于几何距离 |

## 4. Go2 机身足迹模型

公式图片：![机身足迹与运动预测](formula_images/03_footprint_motion_model.png)

局部预测状态和控制量定义为

$$
\mathbf x_t=[x_t,y_t,\theta_t]^\mathsf T,
\qquad
\mathbf u_t=[v_t,\omega_t]^\mathsf T.
$$

采用离散单轨模型预测短时位姿：

$$
\begin{aligned}
x_{t+1}&=x_t+v_t\cos\theta_t\Delta t,\\
y_{t+1}&=y_t+v_t\sin\theta_t\Delta t,\\
\theta_{t+1}&=\operatorname{wrap}(\theta_t+\omega_t\Delta t).
\end{aligned}
$$

基础机身长宽为 $L=0.72\,\mathrm m$、$W_b=0.42\,\mathrm m$，四周加入安全余量 $m_s=0.05\,\mathrm m$：

$$
L_f=L+2m_s,
\qquad
W_f=W_b+2m_s.
$$

局部矩形足迹 $\mathcal F_0$ 变换到预测位姿：

$$
\mathcal F(\mathbf x_t)=\mathbf p_t+R(\theta_t)\mathcal F_0,
\qquad
\mathbf p_t=[x_t,y_t]^\mathsf T.
$$

足迹碰撞指示为

$$
I_t=\mathbb I\left[
\mathcal F(\mathbf x_t)\cap\mathcal O\ne\varnothing
\right].
$$

| 符号 | 含义 |
| --- | --- |
| $t$ | MPPI 预测步编号 |
| $\mathbf x_t$ | 第 $t$ 步预测状态 |
| $x_t,y_t,\theta_t$ | 前向位置、横向位置和偏航角 |
| $\mathbf u_t$ | 第 $t$ 步控制量 |
| $v_t,\omega_t$ | 前向线速度和偏航角速度 |
| $\Delta t$ | 预测时间步长，当前为 $0.1\,\mathrm s$ |
| $\operatorname{wrap}$ | 将角度限制到 $[-\pi,\pi)$ |
| $L,W_b$ | Go2 基础机身足迹长度和宽度 |
| $m_s$ | 足迹安全余量 |
| $L_f,W_f$ | 加入安全余量后的足迹尺寸 |
| $R(\theta_t)$ | 二维旋转矩阵 |
| $\mathcal F_0$ | 机器人原点处的矩形足迹采样点集合 |
| $\mathcal F(\mathbf x_t)$ | 变换到预测位姿后的足迹 |
| $I_t$ | 足迹是否与障碍相交的二值变量 |

## 5. 双层代价 FMM 引导的足迹 MPPI（Ours）

### 5.1 控制序列采样

公式图片：![MPPI采样与更新](formula_images/05_mppi_sampling_update.png)

以名义控制序列 $\bar{\mathbf U}$ 为中心采样 $K$ 条候选控制序列：

$$
\mathbf U^{(k)}=\operatorname{clip}\left(
\bar{\mathbf U}+\boldsymbol\epsilon^{(k)}
\right),
\qquad k=1,\ldots,K.
$$

随机扰动采用时间相关滤波：

$$
\boldsymbol\epsilon_t^{(k)}=
0.65\boldsymbol\epsilon_{t-1}^{(k)}
+0.35\boldsymbol\eta_t^{(k)}.
$$

当前 $K=384$，预测时域 $T=20$，预测步长 $\Delta t=0.1\,\mathrm s$，每条轨迹预测 $2\,\mathrm s$。

| 符号 | 含义 |
| --- | --- |
| $\bar{\mathbf U}=[\bar{\mathbf u}_0,\ldots,\bar{\mathbf u}_{T-1}]$ | 上一轮滚动得到的名义控制序列 |
| $\mathbf U^{(k)}$ | 第 $k$ 条候选控制序列 |
| $K$ | 每轮采样数量，当前为 384 |
| $T$ | 预测步数，当前为 20 |
| $\boldsymbol\epsilon_t^{(k)}$ | 第 $k$ 条序列在第 $t$ 步的时间相关扰动 |
| $\boldsymbol\eta_t^{(k)}$ | 独立高斯噪声 |
| $\operatorname{clip}$ | 将 $v$、$\omega$ 限制在允许范围内 |

### 5.2 候选轨迹总代价

公式图片：![MPPI候选轨迹代价](formula_images/04_mppi_trajectory_cost.png)

第 $k$ 条候选轨迹总代价为

$$
J_k=J_{\mathrm{track}}+J_{\mathrm{terminal}}+J_{\mathrm{heading}}
+J_{\mathrm{collision}}+J_{\mathrm{clearance}}
+J_{\mathrm{smooth}}+J_{\mathrm{control}}.
$$

路径跟踪与终端代价：

$$
J_{\mathrm{track}}=5\sum_{t=1}^{T}
\left\|\mathbf p_t^{(k)}-\mathbf r_t\right\|_2^2,
$$

$$
J_{\mathrm{terminal}}=15
\left\|\mathbf p_T^{(k)}-\mathbf r_T\right\|_2^2.
$$

终端航向代价：

$$
J_{\mathrm{heading}}=3\,
\operatorname{wrap}(\theta_T^*-\theta_T^{(k)})^2.
$$

足迹碰撞代价：

$$
J_{\mathrm{collision}}=2500
\sum_{t=1}^{T}I_t^{(k)}.
$$

障碍净空代价：

$$
J_{\mathrm{clearance}}=18\sum_{t=1}^{T}
\left[
\frac{\max(0,0.65-d_t^{(k)})}{0.65}
\right]^2.
$$

控制变化代价：

$$
J_{\mathrm{smooth}}=
1.5\sum_{t=2}^{T}(v_t-v_{t-1})^2
+4\sum_{t=2}^{T}(\omega_t-\omega_{t-1})^2.
$$

控制量代价：

$$
J_{\mathrm{control}}=
0.08\sum_{t=1}^{T}(v_{\max}-v_t)^2
+0.35\sum_{t=1}^{T}\omega_t^2.
$$

| 符号 | 含义 |
| --- | --- |
| $J_k$ | 第 $k$ 条候选轨迹总代价 |
| $\mathbf p_t^{(k)}$ | 第 $k$ 条轨迹在第 $t$ 步的位置 |
| $\mathbf r_t$ | 沿双层代价 FMM 走廊插值得到的第 $t$ 个参考点 |
| $\mathbf r_T$ | 预测时域末端参考点 |
| $\theta_T^{(k)}$ | 第 $k$ 条轨迹的末端预测航向 |
| $\theta_T^*$ | 指向末端参考点的目标航向 |
| $I_t^{(k)}$ | 第 $k$ 条轨迹第 $t$ 步的足迹碰撞指示 |
| $d_t^{(k)}$ | 预测中心点到最近障碍的距离 |
| $v_t,\omega_t$ | 候选序列第 $t$ 步的线速度和角速度 |
| $v_{\max}$ | MPPI 允许的最大前向速度 |
| 5、15、3、2500、18、1.5、4、0.08、0.35 | 当前工程实现中的各代价权重，不是无量纲通用常数 |

### 5.3 路径积分加权更新

先减去最小代价以提高指数计算稳定性：

$$
\rho=\min_kJ_k.
$$

候选序列归一化权重为

$$
w_k=
\frac{\exp[-(J_k-\rho)/\lambda]}
{\sum_{j=1}^{K}\exp[-(J_j-\rho)/\lambda]}.
$$

更新名义控制序列：

$$
\bar{\mathbf U}\leftarrow
\sum_{k=1}^{K}w_k\mathbf U^{(k)}.
$$

系统仅执行第一个控制量，并进行角速度低通和控制增量限制：

$$
\mathbf u_{\mathrm{cmd}}=\bar{\mathbf u}_0,
$$

$$
\omega_{\mathrm{cmd}}\leftarrow
0.65\omega_{\mathrm{prev}}+0.35\omega_{\mathrm{cmd}},
$$

$$
|\Delta v|\le0.04,
\qquad
|\Delta\omega|\le0.08.
$$

| 符号 | 含义 |
| --- | --- |
| $\rho$ | 当前样本集合中的最小轨迹代价 |
| $w_k$ | 第 $k$ 条候选控制序列的归一化权重 |
| $\lambda$ | MPPI 温度参数，当前为 8.0 |
| $j$ | 权重归一化求和使用的样本索引 |
| $\mathbf u_{\mathrm{cmd}}$ | 当前发送给 HIMLoco 的速度命令 |
| $\omega_{\mathrm{prev}}$ | 上一控制周期实际下发的角速度 |
| $\Delta v,\Delta\omega$ | 相邻 50 Hz 控制周期的速度增量 |

## 6. SAPF 对比方法

公式图片：![外部对比方法公式](formula_images/06_comparison_planners.png)

目标吸引力定义为

$$
\mathbf F_{\mathrm{att}}=
k_a\frac{\mathbf q_g-\mathbf q}{\|\mathbf q_g-\mathbf q\|_2}.
$$

障碍径向排斥力幅值为

$$
M_{\mathrm{rep}}=
k_r\left(
\frac{1}{d-r_{\mathrm{safe}}}
-\frac{1}{r_{\mathrm{inf}}-r_{\mathrm{safe}}}
\right)
\frac{1}{(d-r_{\mathrm{safe}})^2}.
$$

SAPF 将排斥方向旋转 $\gamma$ 形成绕流：

$$
\mathbf F_{\mathrm{SAPF}}=
\mathbf F_{\mathrm{att}}+
R(\gamma)M_{\mathrm{rep}}\hat{\mathbf e}_{\mathrm{rep}}.
$$

控制输出为

$$
\theta_f=\operatorname{atan2}(F_y,F_x),
\qquad
\omega=\operatorname{clip}(k_\omega\theta_f,-\omega_{\max},\omega_{\max}).
$$

| 符号 | 含义 |
| --- | --- |
| $\mathbf q,\mathbf q_g$ | 当前栅格位置和目标栅格位置 |
| $k_a,k_r$ | 吸引力和排斥力增益 |
| $d$ | 当前点到最近障碍的距离 |
| $r_{\mathrm{safe}}$ | 硬安全距离 |
| $r_{\mathrm{inf}}$ | 障碍排斥力影响距离 |
| $M_{\mathrm{rep}}$ | 排斥力幅值 |
| $\hat{\mathbf e}_{\mathrm{rep}}$ | 由最近障碍指向当前位置的单位向量 |
| $R(\gamma)$ | 将排斥力旋转 $\gamma$ 的二维旋转矩阵 |
| $\gamma$ | 随净空变化并锁定左右符号的旋转角 |
| $\mathbf F_{\mathrm{SAPF}}$ | 吸引力与旋转排斥力合力 |
| $\theta_f$ | 合力对应的期望航向 |

## 7. PS-DWA 对比方法

由当前速度和加速度约束构造动态窗口：

$$
\mathcal V_t=
[v_t-a_v\Delta t,v_t+a_v\Delta t]
\times
[\omega_t-a_\omega\Delta t,\omega_t+a_\omega\Delta t].
$$

对候选 $(v,\omega)$ 使用单轨模型前向模拟，并计算

$$
S(v,\omega)=4S_d+2S_h+0.5S_v.
$$

其中

$$
S_d=\frac{1}{\|\mathbf p_T-\mathbf p_{\mathrm{ref}}\|_2+1},
\qquad
S_h=\frac{\pi-|\Delta\theta_T|}{\pi},
\qquad
S_v=\frac{v}{v_{\max}}.
$$

模式搜索求取

$$
(v^*,\omega^*)=
\arg\max_{(v,\omega)\in\mathcal V_t}S(v,\omega),
$$

若模式搜索一轮没有改进，则搜索步长减半，直至达到最小步长或最大评价次数。

| 符号 | 含义 |
| --- | --- |
| $\mathcal V_t$ | 当前控制周期允许的线速度、角速度动态窗口 |
| $a_v,a_\omega$ | 最大线加速度和最大角加速度 |
| $\mathbf p_T$ | 候选速度轨迹的预测末端位置 |
| $\mathbf p_{\mathrm{ref}}$ | A* 局部参考路径上的前视点 |
| $S_d$ | 预测末端接近参考点的得分 |
| $S_h$ | 预测末端朝向参考点的得分 |
| $S_v$ | 前进速度得分 |
| $\Delta\theta_T$ | 预测末端航向与参考点方向的夹角 |
| $(v^*,\omega^*)$ | 模式搜索得到的最优速度命令 |

## 8. iPlanner 对比方法

iPlanner 使用公开预训练网络。本文工程将米制深度图和机器人坐标系局部目标输入网络：

$$
(\hat{\mathcal P},\hat f)=g_{\boldsymbol\theta}(D,\mathbf g).
$$

再由统一路径跟踪接口将预测路径转换为 HIMLoco 速度命令：

$$
\mathbf u=\mathcal T(\hat{\mathcal P},\hat f).
$$

| 符号 | 含义 |
| --- | --- |
| $g_{\boldsymbol\theta}$ | 参数为 $\boldsymbol\theta$ 的 iPlanner 预训练网络 |
| $D$ | 经过尺寸和单位适配的深度图 |
| $\mathbf g$ | 限制在局部感知范围内的目标向量 |
| $\hat{\mathcal P}$ | 网络预测的局部路径或路径节点序列 |
| $\hat f$ | 网络预测的 fear/风险量 |
| $\mathcal T$ | 本文统一的路径跟踪与速度限幅接口 |
| $\mathbf u=[v,\omega]^\mathsf T$ | 发送给 HIMLoco 的速度命令 |

> iPlanner 的网络损失和结构应引用其原论文与官方代码，不应把网络训练公式写成本文原创。
> 本文比较中使用官方预训练模型，只完成深度单位、输入尺寸、目标范围和速度接口适配。

## 9. HIMLoco 底层强化学习控制

公式图片：![HIMLoco与PPO公式](formula_images/07_himloco_ppo.png)

HIMLoco 根据当前观测、历史观测和估计隐变量输出 12 维关节动作：

$$
\mathbf a_t=\pi_{\boldsymbol\theta}
(\mathbf o_t,\mathbf h_t,\hat{\mathbf z}_t).
$$

动作转换为目标关节位置：

$$
\mathbf q_t^{\mathrm{des}}=
\mathbf q^{\mathrm{def}}+s_a\mathbf a_t.
$$

PPO 新旧策略概率比为

$$
r_t(\boldsymbol\theta)=
\frac{\pi_{\boldsymbol\theta}(\mathbf a_t|\mathbf o_t)}
{\pi_{\boldsymbol\theta_{\mathrm{old}}}(\mathbf a_t|\mathbf o_t)}.
$$

裁剪代理目标为

$$
L_{\mathrm{clip}}=
\mathbb E_t\left[
\min\left(
r_t\hat A_t,
\operatorname{clip}(r_t,1-\epsilon,1+\epsilon)\hat A_t
\right)
\right].
$$

价值函数损失为

$$
L_V=\mathbb E_t
\left[(V_{\boldsymbol\psi}(\mathbf o_t)-\hat R_t)^2\right].
$$

工程训练总损失可概括为

$$
L=-L_{\mathrm{clip}}+c_vL_V-c_e\mathcal H(\pi_{\boldsymbol\theta})
+L_{\mathrm{est}}+L_{\mathrm{swap}}.
$$

| 符号 | 含义 |
| --- | --- |
| $\pi_{\boldsymbol\theta}$ | 参数为 $\boldsymbol\theta$ 的策略网络 |
| $\mathbf o_t$ | 当前本体观测和速度命令 |
| $\mathbf h_t$ | 多步历史观测 |
| $\hat{\mathbf z}_t$ | 历史信息编码得到的速度/环境隐变量 |
| $\mathbf a_t$ | 12 个关节的归一化动作 |
| $\mathbf q_t^{\mathrm{des}}$ | 12 个关节目标位置 |
| $\mathbf q^{\mathrm{def}}$ | 默认站立关节位置 |
| $s_a$ | 动作缩放系数 |
| $r_t$ | 新旧策略对同一动作的概率比 |
| $\boldsymbol\theta_{\mathrm{old}}$ | 采样数据时使用的旧策略参数 |
| $\hat A_t$ | 优势函数估计 |
| $\epsilon$ | PPO 裁剪范围参数，代码默认值为 0.2 |
| $V_{\boldsymbol\psi}$ | 参数为 $\boldsymbol\psi$ 的价值网络 |
| $\hat R_t$ | 回报目标 |
| $c_v,c_e$ | 价值损失系数和熵系数 |
| $\mathcal H$ | 策略分布熵 |
| $L_{\mathrm{est}}$ | 状态/速度估计损失 |
| $L_{\mathrm{swap}}$ | HIM 表征学习中的交换一致性损失 |

## 10. 实验评价指标

公式图片：![实验评价指标](formula_images/08_evaluation_metrics.png)

### 10.1 速度跟踪误差

$$
e_v=\frac{1}{N}\sum_{t=1}^{N}
|v_t^{\mathrm{cmd}}-v_t^{\mathrm{real}}|.
$$

### 10.2 姿态与角速度稳定性

$$
e_{\mathrm{ori}}=
\frac{1}{N}\sum_{t=1}^{N}
\sqrt{\phi_t^2+\vartheta_t^2},
$$

$$
e_{\mathrm{ang}}=
\frac{1}{N}\sum_{t=1}^{N}
\sqrt{\omega_{x,t}^2+\omega_{y,t}^2}.
$$

### 10.3 控制平滑性

$$
S_{\omega}=
\frac{1}{N-1}\sum_{t=2}^{N}
|\omega_t^{\mathrm{cmd}}-\omega_{t-1}^{\mathrm{cmd}}|.
$$

### 10.4 能耗代理指标

$$
E_{\tau}=
\frac{1}{N}\sum_{t=1}^{N}
\sum_{j=1}^{12}\tau_{j,t}^2.
$$

### 10.5 平均规划时间与成功率

$$
\bar t_p=\frac{1}{N_p}\sum_{i=1}^{N_p}t_{p,i},
$$

$$
\operatorname{SuccessRate}=
\frac{N_{\mathrm{success}}}{N_{\mathrm{trial}}}\times100\%.
$$

| 符号 | 含义 |
| --- | --- |
| $N$ | 一次试验中的有效控制步数 |
| $v_t^{\mathrm{cmd}},v_t^{\mathrm{real}}$ | 指令前向速度和实际前向速度 |
| $\phi_t,\vartheta_t$ | 机身横滚角和俯仰角 |
| $\omega_{x,t},\omega_{y,t}$ | 机身横滚和俯仰角速度 |
| $S_{\omega}$ | 相邻控制步角速度命令平均绝对变化量 |
| $\tau_{j,t}$ | 第 $t$ 步第 $j$ 个关节的输出力矩 |
| $E_{\tau}$ | 平均平方力矩和，作为能耗代理而非真实电能 |
| $N_p$ | 一次试验中的规划调用次数 |
| $t_{p,i}$ | 第 $i$ 次规划耗时 |
| $N_{\mathrm{success}}$ | 成功到达且未触发碰撞、卡住、掉落或超时的试验数 |
| $N_{\mathrm{trial}}$ | 试验总数 |
