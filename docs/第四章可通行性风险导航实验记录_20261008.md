# 第四章可通行性风险导航实验记录

## 1. 方法定位

第四章不复现完整 ViPlanner 训练链路，而采用“连续可通行性代价估计 + 第三章局部规划器”的路线。
当前第一版先实现解析可通行性代价层，作为后续 RGB-D 小模型训练的标签定义和闭环上限。

方法名称暂定为：

**基于连续可通行性估计的风险感知局部导航方法**

核心对标思想：

- ViPlanner, ICRA 2024：融合深度与语义/代价地图进行局部视觉导航。
- Traversability-aware / risk-aware navigation：不只判断硬障碍，而是对粗糙地形、台阶和不稳定区域赋予连续风险。

## 3. 代价定义

当前可通行风险图为 $[0,1]$ 连续 BEV 代价，由三部分组成：

1. 局部高度起伏风险：由单格内 `max_z - min_z` 归一化得到。
2. 前向台阶风险：由当前格与更近格之间的高度突变得到。
3. 硬障碍风险：规划器障碍格直接置为 1。

该代价图同时进入：

- FMM：降低高风险区域传播速度，使参考路径绕开风险区域。
- U-MPPI：增加候选轨迹中心点经过高风险区域的代价。

## 5. 当前判断

第四章不能只复用第三章的随机障碍走廊作为正式实验。该场景主要考察硬障碍避障，第三章方法已经足够强，连续可通行代价只能增加保守性，优势不明显。

第四章正式实验应新增“地形风险选择”场景，例如：

- 左右两条可达通道：一条短但粗糙/台阶风险高，一条稍长但平整。
- 草地/碎石/低矮台阶混合区域：几何上不是硬障碍，但通行代价不同。
- 纯深度几何方法会倾向短路径，风险感知方法应选择低风险路线。

下一步先做解析代价层闭环上限实验，再训练轻量 RGB-D 模型去预测同一张连续代价图。

## 7. 主线实验 1：RUGD 可通行性风险识别

### 7.1 实验目的

本实验不再增加过多横向对比方法，先验证第四章主线是否成立：

`野外 RGB 图像 -> 可通行性风险图 -> 局部规划风险代价`

其中可通行性风险图将草地、道路等区域作为低风险可通行区域，将碎石、灌木等区域作为中风险区域，将树木、水面、车辆、行人等区域作为高风险区域。

### 7.2 训练配置

输出目录：

`assets/runs/traversability/rugd_tinyunet_main_768e4_cache_20261008/`

运行命令：

```bash
conda run -n himloco python legged_gym/legged_gym/scripts/train_rugd_traversability.py \
  --dataset assets/datasets/rugd_traversability_train2_v1 \
  --output assets/runs/traversability/rugd_tinyunet_main_768e4_cache_20261008 \
  --epochs 4 \
  --batch-size 8 \
  --height 96 \
  --width 144 \
  --width-mult 8 \
  --limit 768 \
  --num-workers 0 \
  --log-interval 20 \
  --cache-in-memory
```

`--cache-in-memory` 用于将缩放后的图像和标签缓存到内存中，避免每个 epoch 重复从机械盘读取和缩放 JPEG/PNG。

### 7.3 训练结果

| 指标 | 数值 |
| --- | ---: |
| 训练样本 | 614 |
| 验证样本 | 154 |
| 设备 | CUDA |
| 训练耗时 | 254.36 s |
| 最优 mIoU | 0.775 |
| pixel accuracy | 0.878 |
| 低风险类 IoU | 0.767 |
| 中风险类 IoU | 0.702 |
| 障碍类 IoU | 0.855 |

相比 256 张预实验，本实验的中风险类 IoU 从 `0.563` 提升到 `0.702`，说明增加真实野外数据后，模型对碎石、灌木、石床等“不是硬障碍但通行风险更高”的区域识别更稳定。

### 7.4 推理导出接口

新增脚本：

`legged_gym/legged_gym/scripts/infer_rugd_traversability.py`

该脚本将训练好的模型导出为：

- `preview/*_rgb_gt_pred.jpg`：左侧 RGB，中间标签，右侧预测。

运行命令：

```bash

  --dataset assets/datasets/rugd_traversability_train2_v1 \

  --output assets/runs/traversability/rugd_tinyunet_main_768e4_export_128_20261008 \

  --preview-count 12
```

输出目录：

`assets/runs/traversability/rugd_tinyunet_main_768e4_export_128_20261008/`

导出结果验证：

- 已成功导出 128 张预测标签和代价图。
- 预览图显示碎石河床主要被预测为中风险区域，树木、天空边界和车辆等被预测为高风险区域，局部平整草地/道路区域为低风险区域。

### 7.5 本阶段结论

当前主线实验已经证明：不依赖仿真中手工设置的障碍物，也可以从真实野外 RGB 图像中学习得到可通行性风险图。

后续接入导航时，`pred_cost` 可作为局部规划器的视觉风险代价来源。论文中可将本节作为第四章第一部分“面向野外环境的视觉可通行性估计”，下一部分再写“融合可通行性风险代价的 U-MPPI 局部导航”。

### 10.5 当前判断

正式模型的感知效果明显优于 4 epoch 小模型，但闭环导航不如 4 epoch 加权版稳定：

| 模型 | 感知 mIoU | 高风险 IoU | 导航成功率 |
| --- | ---: | ---: | ---: |
| 4 epoch 加权版 | 0.542 | 0.277 | 3/3 |
| 30 epoch 正式版 | 0.722 | 0.502 | 2/3 |

这说明第四章不能只看分割精度，还需要考虑风险图接入局部规划后的行为。正式模型更敏感、更保守，能更好识别 rock，但在 `pred_cost replay` 适配下可能使局部规划更容易陷入保守或停滞。

论文中建议将 30 epoch 正式模型作为感知主结果，将 4 epoch 加权版作为闭环 smoke 成功案例；后续若继续优化，应重点做在线 RGB 到 BEV 的几何投影和风险图平滑，而不是继续盲目增加训练 epoch。
