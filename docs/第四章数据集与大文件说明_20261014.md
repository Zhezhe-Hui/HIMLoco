# 第四章数据集与大文件说明

本仓库已提交第四章实验所需的代码、文档、实验配置、日志摘要、可视化图片、模型权重和导出的风险图结果。

需要注意的是，`assets/datasets` 在仓库中是符号链接：

```text
assets/datasets -> /mnt/data/HIMLoco_storage/datasets
```

真实数据集存放在本机机械硬盘 `/mnt/data` 下，未将数据集本体作为普通 Git 对象上传。原因是部分开源数据文件远超 GitHub 普通仓库限制，例如：

| 文件 | 说明 |
| --- | --- |
| `BASEPROD_labeled_v1_0_1.zip` | 约 5.2 GB |
| `train-00000-of-00010.parquet` | 约 505 MB |
| `train-00001-of-00010.parquet` | 约 453 MB |

这些文件应通过原始数据集来源重新下载，或使用外部网盘、Git LFS、Release asset 等方式单独管理。不要只依赖 `/mnt/data/HIMLoco_storage/datasets` 这个本机路径。

## 数据集公开下载地址

### BASEPROD-D435i labeled subset

本章主线使用的是 BASEPROD 的已标注 RGB-D/thermal 子集，数据集页面如下：

- Zenodo 记录页：<https://zenodo.org/records/15496884>
- DOI：<https://doi.org/10.5281/zenodo.15496884>
- 直接下载文件：<https://zenodo.org/records/15496884/files/BASEPROD_labeled.zip?download=1>
- BASEPROD Hugging Face 页面：<https://huggingface.co/datasets/hassanjbara/BASEPROD>
- BASEPROD 完整数据集入口：<https://doi.org/10.57780/esa-xxd1ysw>
- 数据论文：<https://doi.org/10.1038/s41597-024-03881-1>

下载后建议放置为：

```text
assets/datasets/baseprod_d435i/BASEPROD_labeled.zip
assets/datasets/baseprod_d435i/extracted/BASEPROD/
```

### RUGD Hugging Face parquet mirror

本章预实验中使用的是 RUGD 的 Hugging Face parquet 镜像分片：

- Hugging Face 数据集页：<https://huggingface.co/datasets/nickmuchi/rugd-dataset-all>
- parquet 文件目录：<https://huggingface.co/datasets/nickmuchi/rugd-dataset-all/tree/main/data>
- `train-00000-of-00010.parquet`：<https://huggingface.co/datasets/nickmuchi/rugd-dataset-all/resolve/main/data/train-00000-of-00010.parquet>
- `train-00001-of-00010.parquet`：<https://huggingface.co/datasets/nickmuchi/rugd-dataset-all/resolve/main/data/train-00001-of-00010.parquet>
- `train-00002-of-00010.parquet`：<https://huggingface.co/datasets/nickmuchi/rugd-dataset-all/resolve/main/data/train-00002-of-00010.parquet>

RUGD 官方入口：

- 官方主页：<http://rugd.vision/>
- 官方论文 PDF：<http://rugd.vision/pdfs/RUGD_IROS2019.pdf>

## 训练集重新生成

第四章论文复现实验时，优先使用仓库中的数据准备脚本重新生成训练集：

```bash
python legged_gym/legged_gym/scripts/prepare_baseprod_traversability.py \
  --root assets/datasets/baseprod_d435i/extracted/BASEPROD/FRAMED \
  --output assets/datasets/baseprod_traversability_framed
```

已提交的小型实验结果包括：

- `assets/runs/traversability/` 下的第四章训练摘要、模型权重、预测风险图和可视化图。
- `assets/runs/navigation_benchmark/ch4_*` 下的第四章导航实验日志与汇总表。
- `docs/第四章实验结果整理稿_20261010.md` 和 `docs/第四章可通行性风险导航实验记录_20261008.md`。
