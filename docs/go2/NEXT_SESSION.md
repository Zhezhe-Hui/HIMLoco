# 下次开机：部署与连续导航验收

2026-11-09：机器狗已关机充电，本次只整理电脑源码和离线检查，没有部署或发送运动指令。

## 当前进度

已确认0.30m/s能够真正迈步、网页主动停止有效、一次官方手柄接管使程序退出且归中不恢复。尚未完成持续导航到点、转向、绕障、停止距离和外部里程误差测量。

现有接管测试不等于导航模式：它固定直行，最高0.30m/s，最长8秒，并有2m桥端位移上限；普通实际测试仍是0.10m/s/5秒，该步态已观察到0.10m/s不迈步。不能只延长网页计时或把接管入口当完整导航。

## 开机前可在电脑完成

1. 独立设计受限连续导航任务：支持FMM/MPPI持续更新前向与角速度，目标固定在启动时机身坐标转换后的里程计坐标，不随狗一起向前漂移。保留现有接管、过期、近障、姿态、心跳与退出不恢复保护。
2. 第一轮拟定目标前方2m、左右0、速度上限0.30m/s、最长15秒；这些是待实现和现场确认的测试参数，当前按钮尚未提供。另设独立总时限/位移界限，不能直接取消现有保护或沿用8秒直行专用桥。
3. 处理接近目标时小速度可能不迈步的问题：基于已验证0.30响应安排渐变及到点停止，零速度始终有效；不在有障碍时强制最低速度，不擅自切步态。最低有效运动速度及转向响应仍需实测，不按猜测填写。
4. 离线验证新任务参数、原生桥限幅、手柄锁存、输入过期、近障停车、超时退出与到点连续确认。网页显示真实当前模式、目标及退出原因。

## 下次开机后的顺序

| 阶段 | 操作与通过条件 |
| --- | --- |
| 1. 连接与部署 | 连接GO2-OURS，SSH核对盒子地址和时间；确认没有运行任务后执行deploy/deploy.sh。保留板载标定、runs及依赖，旧目录迁移到go2_web/go2_runtime。自启动仅连接输入。 |
| 2. 静态复核 | 相机与本体状态新鲜；水平地面静止拟合；相机X/Y/偏航估计仍如实标记。近处纸箱在地图上方位/距离正确，无遮挡不误报停车。 |
| 3. 连续影子规划 | 对前方2m目标只规划、不发速度，核对路径、足迹、目标坐标与耗时；不得有持续数据过期或不可达。移动纸箱后图与路径应更新。 |
| 4. 空旷直行到点 | 现场持手柄确认后只做一次。目标前方2m、最高0.30、最长15秒（新模式验收后），前方至少4m空旷平整。狗真正持续迈步、程序因到点停车、保持静止；超时不算到点成功。用卷尺/地面标记核对真实起止位置，不仅看里程计。 |
| 5. 转向到点 | 直行通过后，再做小侧向偏置目标（建议前1.5m、左/右0.3m）。先影子后实际；核对角速度符号、转向响应与机身足迹。受限角速度需先完成新模式软件配置和检查。 |
| 6. 单纸箱绕行 | 先静态确认障碍位置、足迹裕量及可行路线，再绕一只纸箱；通道足够宽，无人进入路径。记录到达/接触/超时/手柄接管，失败不自动重试。 |
| 7. 重复与场景扩展 | 前述通过后，每个简单场景重复至少3次，记录真实终点误差、停车距离、耗时、最小间隙及失败。再增加多障碍与较长距离。 |

每次实际行走前现场确认狗已站稳、空间空旷、手柄可接管；调参或部署不能自动触发运动。任务结束检查恢复只读，不自动开始下一轮。记录保留在盒子，不主动下载到电脑；用户需要论文统计时再指定导出。

## 局部避障的边界

当前不必先部署全局SLAM。短距离局部目标用启动时机身坐标指定，运动中根据本体里程计更新相对目标，深度图持续生成局部障碍与FMM/MPPI轨迹。长距离多段任务、绕大面积遮挡和累计漂移控制另行设计，不能由一次2m到点推断已具备完整全局导航。
