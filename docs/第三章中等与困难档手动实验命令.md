# 第三章中等与困难档手动实验命令

本文档用于在电脑重启后继续第三章正式导航实验。三档统一使用离散高度地形、HIMLoco底层
运动策略、理想VIO、固定seed `20261000..20261029`，对比固定膨胀FMM、软代价FMM和
足迹MPPI。视觉导航命令严禁添加 `--headless`，否则Isaac Gym不会创建深度相机。

## 1. 打开终端后的环境准备

```bash
cd /home/fabu/HIMLoco
export PATH=/home/fabu/miniconda3/envs/himloco/bin:$PATH
export LD_LIBRARY_PATH=/home/fabu/miniconda3/envs/himloco/lib:${LD_LIBRARY_PATH:-}
export PYTHONPATH=/home/fabu/HIMLoco/legged_gym:/home/fabu/HIMLoco/libraries/isaacgym/python
```

## 2. 续跑中等档

中等档为`15大石+3棵树+200小碎石`。2026-09-24关机前已完整完成4个seed、12个任务，
目录中数据均为返回码0。下面的`--resume`会校验原实验配置，只跳过JSON、日志、CSV均完整
且相机正常的任务，然后从第5个seed继续。不要删除原目录，也不要修改scene、方法、seed或VIO。

```bash
python legged_gym/legged_gym/scripts/run_navigation_benchmark.py \
  --scene random_corridor_medium \
  --methods fmm_fixed fmm_soft mppi \
  --seed-start 20261000 --num-seeds 30 --vio ideal \
  --output /home/fabu/HIMLoco/assets/runs/navigation_benchmark/ch3_medium_30seed_20260924 \
  --resume
```

看到`Results: .../ch3_medium_30seed_20260924`才表示90个任务全部结束。若中途再次关机，先按
`Ctrl+C`停止，下一次执行完全相同的命令即可继续。

若困难档中途停止，重新执行上面的命令并在末尾添加`--resume`。

## 4. 分别生成正式统计

每一档完成90个任务后运行对应命令：

```bash
python legged_gym/legged_gym/scripts/analyze_navigation_benchmark.py \
  /home/fabu/HIMLoco/assets/runs/navigation_benchmark/ch3_medium_30seed_20260924

python legged_gym/legged_gym/scripts/analyze_navigation_benchmark.py \
  /home/fabu/HIMLoco/assets/runs/navigation_benchmark/ch3_hard_30seed_20260924
```

分析脚本会生成`statistical_analysis.json`和`statistical_analysis.md`，并进行30-seed配对检验。
若同一seed下三种方法的障碍布局哈希不同，脚本会直接报错，不应使用该组结果。

## 5. 完整性检查

对中等档执行：

```bash
cd /home/fabu/HIMLoco
find assets/runs/navigation_benchmark/ch3_medium_30seed_20260924 \
  -maxdepth 1 -name '*_seed*.json' | wc -l
find assets/runs/navigation_benchmark/ch3_medium_30seed_20260924 \
  -maxdepth 1 -name '*_seed*.log' | wc -l
grep -l 'headless 下无法创建相机' \
  assets/runs/navigation_benchmark/ch3_medium_30seed_20260924/*.log | wc -l
```

困难档将路径中的`medium`换成`hard`。正确结果应依次为`90`、`90`、`0`，且
`statistical_analysis.json`中的`paired_layout_hashes_verified`应为`true`。还应检查
`summary.json`中每种方法的`trials`均为30。

## 6. 与简单档保持一致的汇报指标

每档均报告成功率及95% Wilson置信区间、失败类型、成功样本到达时间和路程、角速度指令
总变差、角速度符号翻转次数、平均/P95规划耗时、能耗、最小净空、碰撞与脱困次数。成功率
使用同seed的McNemar精确检验；连续指标只在双方共同成功seed上使用Wilcoxon配对检验。

简单档已完成90/90：固定FMM为17/30，软代价FMM为24/30，MPPI为25/30；数据目录为
`assets/runs/navigation_benchmark/ch3_easy_30seed_20260924/`。中等和困难档必须采用同一套流程，
不得依据中途结果调整参数、删除困难seed或更换成功判据。
