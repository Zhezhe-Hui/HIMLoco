# 第三章中等与困难档手动实验命令

本文档记录第三章正式导航实验的运行与复现命令。三档统一使用离散高度地形、HIMLoco底层
运动策略、理想VIO、固定seed `20261000..20261029`，对比固定膨胀FMM、双层代价FMM和
双层代价FMM引导的足迹MPPI。视觉导航命令严禁添加 `--headless`，否则Isaac Gym不会创建深度相机。

## 1. 打开终端后的环境准备

```bash
cd /home/hzz/project/HIMLoco
export PATH=/home/hzz/miniconda3/envs/himloco/bin:$PATH
export LD_LIBRARY_PATH=/home/hzz/miniconda3/envs/himloco/lib:${LD_LIBRARY_PATH:-}
export PYTHONPATH=/home/hzz/project/HIMLoco/legged_gym:/home/hzz/project/HIMLoco/libraries/isaacgym/python
```

## 2. 复现或续跑中等档

中等档为`15大石+3棵树+200小碎石`，现已完成90/90。下面的`--resume`会校验原实验配置，
只跳过JSON、日志、CSV均完整且相机正常的任务；结果完整时执行它不会重复运行。不要删除
原目录，也不要修改scene、方法、seed或VIO。

```bash
python legged_gym/legged_gym/scripts/run_navigation_benchmark.py \
  --scene random_corridor_medium \
  --methods fmm_fixed fmm_soft mppi \
  --seed-start 20261000 --num-seeds 30 --vio ideal \
  --output /home/hzz/project/HIMLoco/assets/runs/navigation_benchmark/ch3_medium_30seed_20260924 \
  --resume
```

看到`Results: .../ch3_medium_30seed_20260924`才表示90个任务全部结束。若中途再次关机，先按
`Ctrl+C`停止，下一次执行完全相同的命令即可继续。

## 3. 复现或续跑困难档

困难档为`20大石+4棵树+400小碎石`，现已完成90/90。

```bash
python legged_gym/legged_gym/scripts/run_navigation_benchmark.py \
  --scene random_corridor_hard \
  --methods fmm_fixed fmm_soft mppi \
  --seed-start 20261000 --num-seeds 30 --vio ideal \
  --output /home/hzz/project/HIMLoco/assets/runs/navigation_benchmark/ch3_hard_30seed_20260924 \
  --resume
```

若困难档中途停止，重新执行上面的命令并在末尾添加`--resume`。

## 4. 分别生成正式统计

每一档完成90个任务后运行对应命令：

```bash
python legged_gym/legged_gym/scripts/analyze_navigation_benchmark.py \
  /home/hzz/project/HIMLoco/assets/runs/navigation_benchmark/ch3_medium_30seed_20260924

python legged_gym/legged_gym/scripts/analyze_navigation_benchmark.py \
  /home/hzz/project/HIMLoco/assets/runs/navigation_benchmark/ch3_hard_30seed_20260924
```

分析脚本会生成`statistical_analysis.json`和`paper_table.csv`，并进行30-seed配对检验。
若同一seed下三种方法的障碍布局哈希不同，脚本会直接报错，不应使用该组结果。

## 5. 完整性检查

对中等档执行：

```bash
cd /home/hzz/project/HIMLoco
find assets/runs/navigation_benchmark/ch3_medium_30seed_20260924 \
  -maxdepth 1 -name '*_seed*.json' | wc -l
find assets/runs/navigation_benchmark/ch3_medium_30seed_20260924 \
  -maxdepth 1 -name '*_seed*.log' | wc -l
grep -l 'headless 下无法创建相机' \
  assets/runs/navigation_benchmark/ch3_medium_30seed_20260924/*.log | wc -l
```

困难档将路径中的`medium`换成`hard`。正确结果应依次为`90`、`90`、`0`，且
`statistical_analysis.json`中的`paired_layout_hashes_verified`应为`true`。还应检查
`summary.json`中每种方法的`trials`均为30。

## 6. 与简单档保持一致的汇报指标

每档均报告成功率及95% Wilson置信区间、失败类型、成功样本到达时间和路程、角速度指令
总变差、角速度符号翻转次数、平均/P95规划耗时、能耗、最小净空、碰撞与脱困次数。成功率
使用同seed的McNemar精确检验；连续指标只在双方共同成功seed上使用Wilcoxon配对检验。

三档均已完成90/90。成功数分别为：简单档固定膨胀FMM 17、双层代价FMM 24、MPPI 25；中等档
10、10、20；困难档3、5、14。三档必须采用同一套流程，不得依据结果调整参数、删除困难
seed或更换成功判据。

简单档运行于RTX 3080 Ti；中等档前4个seed来自RTX 3080 Ti，其余来自RTX 4060；困难档
运行于RTX 4060。因此规划耗时只适合在同一难度内部比较三种方法，不应直接跨难度解释绝对
耗时变化。论文若要求三档规划耗时严格可比，应在同一机器上重跑全部三档。
